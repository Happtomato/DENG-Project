# Documentation guide

Start with the [root README](../README.md). The maintained project documents are:

| Document | Use |
| --- | --- |
| [RUN_COMMANDS.md](RUN_COMMANDS.md) | Setup, safe operation, seed import/export, SQL checks, and shutdown |
| [ARCHITECTURE.md](ARCHITECTURE.md) | Architecture v0.2, data model, orchestration, failures, and decisions |
| [MIDTERM_AUDIT.md](MIDTERM_AUDIT.md) | Midterm checklist with dated evidence and limitations |
| [MEDIAMARKT.md](MEDIAMARKT.md) | MediaMarkt parsing and collection rules |

`archive/` contains superseded phase reports and inactive phase-1 SQL. Some reports retain their original German wording as historical records; they are not current setup instructions. `evidence/` contains saved test, SQL, and run evidence. Neither directory is executed by Docker or Prefect. The current data-folder map is in [data/README.md](../data/README.md).
