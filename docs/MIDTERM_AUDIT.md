## Checks and practical limits

On 20 October, `make check` passed (Python syntax, Svelte/TypeScript with zero errors and warnings, Prettier/ESLint); `make test` passed **75/75 Python** and **14/14 frontend integration** tests; the frontend build and `git diff --check` passed. The bundled Parquet snapshot was imported into an isolated empty test schema: 26 products, 34 offers, 63 observations, and 3,752 chart points were preserved; a second import was rejected. The original DB and volumes were not reset. Test-container HTTP checks use fixtures/mocks and triggered no extra live requests.

On 21 October, the automatically scheduled DAILY run `20261021T015016086824Z` selected 22 database offers and made nine HTTP requests. Five successful product fetches added five MediaMarkt observations; three attempts disconnected. Prefect correctly marked the technical partial outcome **Failed**, while retaining the five successful DB rows. It was due at 03:00 but began at 03:50 because the Mac slept; macOS logs show another sleep from 03:50:10 to a brief wake at 04:49:38. A Requests socket timeout cannot keep a host awake. A later DAILY run, already present when this audit was updated, added seven further observations. A fresh read-only `verify` then reported **26 products, 34 offers, 75 observations, 83 loaded Raw files, 18 rejected Raw files, zero import errors, zero invalid CHF prices, and zero duplicate offer/timestamp pairs**. At that point, the seed bundle represented the earlier 63-observation snapshot.

The Raw JSON files referenced by `raw_import.path` are kept at their original paths to preserve provenance and REPLAY. Seven manually supplied Digitec chart JSONs were moved unchanged from `data/raw/digitec/manual import/` to `data/import/digitec/manual-charts/`; their manifest paths were updated. An old Digitec mock now lives with test fixtures, and a one-off live-test catalog is archived under `docs/evidence/phase2/`. No JSON was deleted. `data/catalog/runs/` contains run evidence, not disposable cache. Saved HTML is retained because transformation can use it to verify original product details.

The old zero-byte `data/seed/data.parquet` placeholder was replaced by the genuine `data/seed/midterm-2026-10-25/` bundle. Its directory was renamed on 25 October, but its rows remain the earlier 79-observation snapshot. It and newly collected Raw/HTML evidence need deliberate review for the submission commit. `.env` and credentials must stay out. Digitec automated access is not approved; its historical retailer chart points are not our own daily observations. A reliable always-on scheduler host remains an open decision. None of the final-phase cloud work is needed for the local midterm data flow.
